# MusicUI

## Как работает

Сервер читает системную медиасессию Windows (или Spotify Web API, если выбран этот режим),
параллельно снимает звук с процесса плеера и считает по нему спектр. Всё лежит в памяти и
отдаётся по HTTP на `127.0.0.1:8770`. Скрипт в игре 15 раз в секунду дёргает `/tick` - позиция,
полосы эквалайзера, номер текущей строки текста - и раз в секунду `/state` за тем, что меняется
редко: трек, обложка, окно текста. Когда ничего не меняется, `/state` уходит в режим раз в
5 секунд. Ни базы, ни файлов состояния: сервер перезапустился - всё собралось заново.

## Что нужно

- Windows 10 или 11
- Python 3.13 - только если запускать из исходников

## Установка

Сервер - `dist\MusicUI.exe`. При запуске спросит режим, дальше просто оставь окно висеть.

Скрипт - скопировать `scripts\MusicUI.lua` в `..\scripts\`

Хост сервера в скрипте прописан константой `SERVER = "127.0.0.1:8770"` (строка 83). Если меняешь
порт у сервера, поменяй и там.

## Режимы

**Системный** - работает с любым плеером Windows: Spotify, Яндекс Музыка, браузер. Ключи и
Premium не нужны. Позиция трека берётся из медиасессии, поэтому её точность зависит от плеера;

**Spotify** - точная позиция, но нужен Premium и свои ключи приложения.
Настраиваются один раз клавишей `k` в меню выбора режима, там же пошаговая инструкция. Ключи
лягут в `secrets.json` рядом с сервером - это доступ к аккаунту, файл никому не показывай.
Если Spotify не поднялся, сервер сам скатится в системный режим и скажет причину.

## Управление

Клик по острову - раскрыть или свернуть. В раскрытом виде работают кнопки назад / пауза / вперёд
и полоса прогресса: клик по ней перематывает. Пока курсор над островом, клики не проходят в игру,
так что юнит никуда не побежит.

## Настройки

Плеер: включение, стиль (черный или размытие), масштаб, позиция по X, отступ сверху,
автосворачивание, скрывать когда нет трека, показывать вне игры, акцент из обложки.

Модули: лирика - отдельной капсулой или внутри острова, подсветка по словам, ширина капсулы;
эквалайзер - от 3 до 12 полос, чувствительность, «только музыка» (тогда разговоры в Discord
полосы не двигают).

## Запуск из исходников

```
pip install -r requirements.txt
python -m musicui
```

## Сборка

```
python tools\build.py
```

## Структура

```
musicui/            сервер
  __main__.py       точка входа
  config.py         настройки, пути, ключи Spotify
  server.py         HTTP и роуты
  startup.py        выбор режима, поднятие плеера
  spotify_setup.py  мастер ключей
  audio/            захват звука и спектр
  core/             состояние трека, опрос, обложки, текст, медиаклавиши
  sources/          плееры и провайдеры текста
scripts/            MusicUI.lua — копия для ..\scripts
tools/              сборка .exe
```

## Что стоит знать

Синхронный текст есть не у каждого трека: у редких релизов, ремиксов и свежих загрузок его нет
ни у одного провайдера. Тогда остров просто остаётся без строки, это не поломка.
