# MusicUI

Остров как на айфоне, только висит поверх Доты. Свёрнутый - узкая капсула с обложкой и названием,
кликнул - развернулась: кнопки, полоса прогресса, текст песни с подсветкой по словам и эквалайзер,
который дёргается именно от твоей музыки. Когда музыка молчит, капсула показывает часы.

Плеер подойдёт любой, который винда показывает в своей медиапанели.

> [**Скачать**](https://github.com/But3rflys/MusicUI/releases) // [исходники](https://github.com/But3rflys/MusicUI/tree/main/musicui)

## Что нужно

- Windows 10 или 11 - на старых нужного API просто нет
- Umbrella
- Python 3.13 - только если запускать из исходников

## Установка

1. `MusicUI.lua` в `C:\Umbrella\scripts\`
2. запустить `MusicUI.exe`, он спросит режим - это и есть сервер
3. настройки в `Scripts > MusicUI`

## Автозапуск с Дотой

Чтобы не поднимать сервер руками, есть строка для параметров запуска Доты - при первом запуске
MusicUI сам кладёт её в буфер обмена:

```
"C:\путь\MusicUI.exe" --launch %command%
```

Вставить в Umbrella Loader или напрямую в Steam, **первой, перед остальными параметрами**. Дальше
остров поднимается вместе с игрой и гаснет, когда из неё выходишь. В автозагрузке Windows ничего
не висит: работает ровно столько, сколько идёт матч.

Показать строку снова - `MusicUI.exe --autostart`. Не напоминать - `MusicUI.exe --autostart off`.

## Режимы

**Системный** - работает с любым плеером Windows: Spotify, Яндекс Музыка, браузеры (Chrome,
Яндекс.Браузер, Firefox, Brave). В браузере ловит вообще любое воспроизведение - видос на ютубе,
клип, песню из вк, стрим. Ключи и Premium не нужны. Позиция трека берётся из медиасессии, так что
её точность зависит от плеера.

**Spotify** - точная позиция, но нужен Premium и свои ключи приложения. Настраиваются один раз
клавишей `k` в меню выбора режима, там же пошаговая инструкция. Ключи лягут в `secrets.json` рядом
с сервером - это доступ к аккаунту, файл никому не показывай. Если Spotify не поднялся, сервер сам
скатится в системный режим и скажет причину.

## Управление

Клик по острову - раскрыть или свернуть. В раскрытом виде работают кнопки назад / пауза / вперёд и
полоса прогресса: клик по ней перематывает. Пока курсор над островом, клики не проходят в игру, так
что юнит никуда не побежит.

## Настройки

**Плеер**, шестерёнка «Внешний вид»: стиль (чёрный или размытие), масштаб, позиция по X, отступ
сверху, сворачивать автоматически, часы когда нет музыки, скрывать когда нет трека, показывать вне
игры, пружинка раскрытия. Рядом - акцент из обложки или свой цвет.

**Модули**: лирика - отдельной капсулой или внутри острова, подсветка по словам, ширина капсулы;
эквалайзер - от 3 до 12 полос (по дефолту 5), чувствительность, «только музыка» - тогда разговоры в
Discord полосы не двигают.

## Как работает

Сервер читает системную медиасессию Windows (или Spotify Web API, если выбран этот режим),
параллельно снимает звук с процесса плеера и считает по нему спектр. Всё лежит в памяти и отдаётся
по HTTP на `127.0.0.1:8770`. Скрипт в игре 15 раз в секунду дёргает `/tick` - позиция, полосы
эквалайзера, номер текущей строки текста - и раз в секунду `/state` за тем, что меняется редко:
трек, обложка, окно текста. Когда ничего не меняется, `/state` уходит в режим раз в 5 секунд. Ни
базы, ни файлов состояния: сервер перезапустился - всё собралось заново.

Хост прописан в скрипте константой `SERVER = "127.0.0.1:8770"` (строка 105). Меняешь порт у сервера
- поменяй и там.

## Ключи запуска

```
MusicUI.exe                    спросит режим
MusicUI.exe --autostart        показать строку для Доты
```

## Запуск из исходников

```
pip install -r requirements.txt
python -m musicui
```

## Сборка

```
python tools\build.py
```

## Структура

```
musicui/            сервер
  __main__.py       точка входа
  config.py         настройки, пути, ключи Spotify
  server.py         HTTP и роуты
  startup.py        выбор режима, поднятие плеера
  spotify_setup.py  мастер ключей
  autostart.py      строка для параметров запуска Доты
  console.py        консоль
  procwatch.py      следит, жива ли игра
  audio/            захват звука и спектр
  core/             состояние трека, опрос, обложки, текст, медиаклавиши
  sources/          плееры и провайдеры текста
tools/              сборка .exe
```

## Что стоит знать

Синхронный текст есть не у каждого трека: у редких релизов, ремиксов и свежих загрузок его нет ни у
одного провайдера. Тогда остров просто остаётся без строки, это не поломка - обложка, полосы и
кнопки работают как обычно.
