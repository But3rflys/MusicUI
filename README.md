# MusicUI

## Установка

1. [**скачать**](https://github.com/But3rflys/MusicUI/releases) последнюю версию
2. распаковать архив в любое место/любую папку
3. закинуть `MusicUI.lua` в `..\scripts\`
4. запустить `MusicUI.exe`, следовать инструкциям

## Что стоит знать

Синхронный текст есть не у каждого трека: у ремиксов и свежих загрузок его нет ни у
одного провайдера. Тогда остров просто остается без строки, это не поломка - остальное будет работать как обычно
