# MusicUI

> [**Скачать**](https://github.com/But3rflys/MusicUI/releases) / [исходники](https://github.com/But3rflys/MusicUI)

## Установка

1. `MusicUI.lua` в `..\scripts\`
2. запустить `MusicUI.exe`, следовать инструкциям

## Что стоит знать

Синхронный текст есть не у каждого трека: у ремиксов и свежих загрузок его нет ни у
одного провайдера. Тогда остров просто остается без строки, это не поломка - остальное будет работать как обычно
